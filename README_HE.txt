Weight Health PWA v1

איך מפעילים:
1. חלץ את קובץ ה-ZIP לתיקייה.
2. להפעלה מלאה כ-PWA מומלץ להגיש את התיקייה דרך שרת מקומי (למשל Live Server ב-VS Code) ולפתוח את index.html בדפדפן Chrome.
3. הנתונים נשמרים מקומית בדפדפן באמצעות localStorage.

מסכים קיימים:
- היום
- ארוחות
- מדדי גוף
- פעילות
- דוחות
- הגדרות

חישובים קיימים:
- BMI
- יחס היקף מותניים לגובה (WHtR)
- יחס היקף מותניים לירכיים (WHR)
- סף היקף מותניים לפי מין
- יעד משקל והתקדמות
- קלוריות, חלבון ופעילות יומית
- ציון סיכום של מדדי גוף
- גרף משקל בסיסי
- סיכום 7 ימים

הערה רפואית:
המדדים מיועדים למעקב ולסקר ואינם תחליף לאבחון או להערכת סיכון רפואית מלאה.


גרסה 4.0 — Evidence First
- מרכז ידע והסבר לכל מדד.
- המלצת הפעולה הבאה לפי הנתונים שהוזנו.
- מקורות: NICE, WHO, AHA/ACC, ADA 2026, KDIGO 2024, ACSM, CDC.
- מדדים משלימים מסומנים ואינם מוצגים כאבחנה.
- manifest חדש וזהות PWA חדשה כדי לצמצם cache של התקנות קודמות.
